# JDBC Transactions Practice – Day 05

## Overview
This project is part of the **CG SRM Java Backend (2025–26)** training program.  
It focuses on implementing **JDBC Transactions and database operations** using **Java and MySQL**.

The goal of this practice is to understand how to manage **database transactions, ensure data consistency, and implement ER models using JDBC**.

---

## Learning Objectives
- Understand **JDBC transaction management**
- Implement **commit and rollback operations**
- Work with **database connections using JDBC**
- Implement **ER models in Java applications**
- Practice **structured backend development**
